領航早點名 — GitHub Pages 版

1. 建立新的 GitHub repository，例如 morning-rollcall。
2. 解壓縮 ZIP，將 index.html、sw.js、manifest.webmanifest、icon.svg 上傳到儲存庫最外層。
3. Settings → Pages → Deploy from a branch → main → / (root) → Save。
4. 部署完成後，用 Safari 開啟 Pages 網址，再「加入主畫面」。

功能：每人預設實到；差勤選擇後立即更新下方回報。人員與差勤可新增、修改、刪除。
每天依台灣日期自動重設為實到，同一天保留選擇。
名單設定保留在各自裝置的瀏覽器，清除網站資料會移除設定。
首次連網開啟且顯示離線功能已就緒後，可離線使用。
GitHub Pages 網址可分享同事；各手機資料獨立，不會互相同步。

初始名單包含您提供的八位姓名。若儲存庫設為公開，上傳的原始碼與初始姓名也會公開；可先於 index.html 修改初始名單。
